            02
            
    
              
    Where your code goes is never a guess.
    
              
    Before a review starts, Hunkyard names every destination your source code will reach. Local-only mode is a hard boundary, not a preference.
    
            
    
          
    
          
    
            
      
              
    • Local by default. Ollama, LM Studio, llama.cpp or any OpenAI-compatible server on your machine.
      • 
              
    • Consent per repository. Hosted providers need an explicit opt-in for each repository, and you can revoke it at any time.
      • 
              
    • No silent fallback. If your local model fails, the review stops. It never quietly switches to the cloud.
      •

            04
            
    
              
    Bring the model. Keep the choice.
    
              
    Run reviewers on your own hardware, or opt in to a hosted provider for one repository at a time.
    
            
    
          
    
          
    
            
    
              
    On your machine
    
              
    • Ollama
    • LM Studio
    • llama.cpp
    • Any OpenAI-compatible server
    
            
    
            
    
              
    Hosted, with consent
    
              
    • OpenAI
    • DeepSeek
    • AgentRouter
    
            
    
            
    
              
    Reviewers
    
              
    • Correctness
    • Security
    • Frontend and accessibility
    • Architecture and performance
    • Testing
    
            
    
          
    
          
    
            
    GitHub pull requests
    Review a PR locally with the GitHub CLI. Posting a summary back is a separate, confirmed step.
    
            
    VS Code
    Run reviews and browse their findings without leaving the editor.
    
            
    History that stays
    Sessions, runs and decisions live in a local SQLite database. Export or delete them whenever you like.
